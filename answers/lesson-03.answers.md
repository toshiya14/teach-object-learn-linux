# 第 03 课 · 实验答案

## 实验 A 参考答案（桌面环境）

- Ubuntu 默认桌面环境：**GNOME**。
- 「显示应用程序」图标在屏幕左下角（九宫格）。
- 「文件」管理器类似 Windows 资源管理器，但左侧看到的是 `/home` 等 Linux 目录，而非 C 盘 D 盘。

## 实验 B 参考答案（快照）

- 快照名称参考：「刚装好系统」。
- 恢复快照后，`sl` 命令应当**不存在**：输入 `sl` 会提示 `command not found`。
- 原因：快照记录了打快照那一刻的系统状态；恢复后，之后安装的 `sl` 被"抹掉"，回到干净状态。

## 实验 C 参考答案（系统更新）

```bash
sudo apt update
```

**参考输出（末尾几行，数字因版本而异）**：

```
正在读取软件包列表... 完成
正在分析软件包的依赖关系树... 完成
正在读取状态信息... 完成
已下载 128 kB，耗时 2秒
正在读取软件包列表... 完成
```

- 末尾可能显示"可以升级 X 个软件包"。

```bash
sudo apt upgrade
```

**参考输出（确认环节）**：

```
将会升级 XX 个软件包，新安装 XX 个，删除 XX 个，保留 XX 个。
需要下载 XXX MB 的软件包。
...
Do you want to continue? [Y/n]
```

- 输入 `y` 回车继续，等待完成即可。

## 常见疑问

**Q：输 sudo 密码时为什么看不到输入？**
A：Linux 出于安全，输密码不显示任何字符（连星号都没有）。直接输完回车即可。

**Q：`apt update` 报"无法连接/找不到源"怎么办？**
A：先检查虚拟机是否联网。也可尝试切换国内镜像源（第 31 课会讲）。

**Q：恢复快照后，我的文档还在吗？**
A：快照是"整体回档"，恢复到某快照后，该快照之后产生的所有改动（含文档）都会消失。所以重要文档请单独备份，别只依赖快照。
