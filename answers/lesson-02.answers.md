# 第 02 课 · 实验答案

## 实验 A 参考答案（echo）

```bash
echo "你好，Linux"
```

**参考输出**：

```
你好，Linux
```

- 解释：`echo` 把引号内的文字原样回显到屏幕。

```bash
echo 你好
```

**参考输出**：

```
你好
```

- 解释：不含空格的单词可不加引号；含空格时建议加引号，避免被当成多个参数。

## 实验 B 参考答案（whoami）

**参考输出**：

```
你的用户名
```

- 解释：输出当前有效用户的用户名；未切换身份时，通常是第 01 课安装时设置的名字。

## 实验 C 参考答案（ls /dev）

**常见设备文件**：

| 文件名 | 通常代表 |
| --- | --- |
| `sda` | 一类磁盘命名中的第一块磁盘（不一定存在） |
| `sda1` | `sda` 的第一个分区（不一定存在） |
| `tty` | 终端设备 |
| `null` | "黑洞"，写进去就消失 |
| `zero` | 不断产生 0 的设备 |

- 只需认出 3 个即可，不必全部记住。
- 可优先记录 `tty`、`null`、`zero`。硬盘也可能叫 `vda` 或 `nvme0n1`，请以实际版本和虚拟机配置为准。

## 实验 D 参考答案（ls /proc）

**常见内容**：

- `cpuinfo`：CPU 信息
- `meminfo`：内存信息
- 纯数字目录：每个数字对应一个正在运行进程的编号（PID）

- 解释：这些"文件"是内核临时生成的，反映系统实时状态。

## 常见疑问

**Q：`echo 你好` 和 `echo "你好"` 有区别吗？**
A：这两个示例输出相同。含空格的简单文字不加引号通常也能输出，但空格可能被合并；建议使用英文双引号保留空格。中文本身不要求加引号。

**Q：`ls /dev` 输出太多，记不住怎么办？**
A：正常。本课只需要体会"设备也是文件"这个思想，不需要背设备名。

**Q：`/proc` 里的文件能修改吗？**
A：大部分只读，且是内核临时生成的，不建议（也不需要）去改。
