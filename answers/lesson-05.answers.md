# 第 05 课 · 实验答案

## 实验 A 参考答案（df -h）

**参考输出（节选，数字因机器而异）**：

```
文件系统        容量  已用  可用 已用% 挂载点
/dev/sda2        37G   8.5G   27G   24% /
```

- 根分区的挂载点是 `/`。
- 文件系统类型通常是 `ext4`（可用 `df -hT` 在"类型"列确认）。

## 实验 B 参考答案（stat）

**参考输出（节选）**：

```
  文件：/etc/hostname
  大小：7               块：8          IO 块：4096   普通文件
设备：...  Inode：262146     硬链接：1
权限：(0644/-rw-r--r--)  Uid：(0/root)   Gid：(0/root)
```

- Inode 号：示例为 `262146`（你的机器不同）。
- 大小：`7` 字节（该文件内容很短）。
- 权限：`-rw-r--r--`。

## 实验 C 参考答案（ls -i）

**参考输出**：

```
262146 /etc/hostname
262147 /etc/hosts
```

- 两个文件 inode 号不同，验证"每个文件 inode 号唯一"。

## 常见疑问

**Q：为什么 `stat` 里有三个"时间"（访问/更改/改动）？**
A：分别指"最近读取时间"（访问）、"内容最近修改时间"（更改）、"元信息最近修改时间"（改动）。初学者只需知道 inode 记录了时间信息即可。

**Q：inode 号会被用完吗？**
A：会。inode 数量在格式化时确定，如果存了大量极小文件，可能 inode 先用完而磁盘还有空间。这属于进阶话题，了解即可。

**Q：文件名的长短和 inode 有关系吗？**
A：没有直接关系。文件名存在目录里，inode 只记录内容、权限、属主、时间等元信息。
