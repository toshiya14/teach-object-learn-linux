# 第 01 课 · 实验答案

> 说明：本课实验 A/B 的"答案"以**结果标准**和**参考输出**呈现，因为每台电脑的分区大小、用户名等会因人而异。实验 C 有确定输出，给出参考答案。

## 实验 A 参考答案（创建虚拟机）

**完成标准**：虚拟机成功创建并启动，进入 Ubuntu 安装界面。

| 配置项 | 参考值 |
| --- | --- |
| 名称 | `Ubuntu-26.04` |
| CPU | 2 核 |
| 内存 | 4096 MB |
| 磁盘 | 40 GB |
| 光驱 | 已挂载 `ubuntu-26.04-desktop-*.iso` |

- 如果你在「启动」后看到 Ubuntu 安装欢迎界面，实验 A 即为成功。

## 实验 B 参考答案（安装系统）

**完成标准**：能登录到 Ubuntu 桌面。

分区方案参考（以 40 GB 磁盘为例，实际以安装程序为准）：

```
磁盘大小：40 GB
根分区 / ：约 37 GB
swap 分区：约 3 GB
```

- 自动分区一般会生成 `/`（根分区）和 `swap` 两块；具体大小由安装程序按磁盘容量自动计算，略有出入属正常。
- 用户名、密码为自定义，无标准答案，请务必记住。

## 实验 C 参考答案（终端操作）

### 1. `pwd`

**参考输出**：

```
/home/你的用户名
```

- 解释：`pwd` 打印当前目录，第一次打开终端通常在家目录 `/home/用户名`。

### 2. `ls`

**参考输出**（可能为空或类似）：

```
桌面  文档  下载  音乐  图片  视频
```

- 解释：列出家目录下的内容，中文界面下常见「桌面」「文档」等文件夹。

### 3. `cd /` 后再 `ls`

**参考输出**（常见目录）：

```
bin  boot  dev  etc  home  lib  media  mnt  opt  proc  root  run  sbin  srv  sys  tmp  usr  var
```

- 解释：这是根目录 `/` 下的系统目录骨架，`home` 里装着所有用户的家目录。

### 4. `cd ~`

- 回到家目录，提示符从 `/` 变回 `/home/你的用户名`。

## 常见疑问

**Q：我的 `ls /` 输出和答案不一样，正常吗？**
A：正常。不同 Ubuntu 版本目录略有差异，只要看到 `bin`、`etc`、`home`、`usr` 等主要目录即可。

**Q：分区大小和参考值差很多，算错了吗？**
A：不算。自动分区按磁盘总容量比例分配，你的磁盘如果不是 40 GB，swap 大小也会不同。

**Q：我选择了英文安装，会受影响吗？**
A：不影响学习。命令完全一样，只是界面语言不同。
