## 概念讲解

### 1. 桌面环境是什么

> **比喻**：一部手机，里面的芯片、系统是"里子"，你看到的主屏幕、图标、壁纸是"面子"。Linux 的**桌面环境（Desktop Environment）**就是这层"面子"——一套图形界面。

- 桌面环境负责画出窗口、任务栏、图标、开始菜单等。
- Ubuntu 默认的桌面环境叫 **GNOME**（读作"格诺姆"）。
- 桌面环境是可更换的：换成 KDE、XFCE 就是另一套外观，但底层系统不变。
- 记住：桌面只是"壳"，真正干活的还是内核和命令行。

### 2. 快照是什么（Snapshot）

> **比喻**：玩单机游戏时的**存档点**。存档后，不管你后面怎么乱来、怎么死，都能读档回到存档那一刻。

- **快照（Snapshot）**：记录虚拟机某一时刻的完整状态（系统文件、设置、软件）。
- 打快照后，你可以大胆做实验——装错软件、改坏配置都不怕，随时"读档"恢复。
- 本课程强烈建议：**每次做有风险的操作前，先打一个快照**。

### 3. 软件源与系统更新

> **比喻**：手机上的"应用商店"。Linux 的**软件源（repository）**就是官方的"软件仓库"，里面放着成千上万的软件包。

- **软件包**：软件被打包成的标准文件，方便安装和卸载。
- **软件源**：存放这些软件包的"仓库"地址列表，Ubuntu 官方源、国内镜像源都算。
- **更新**分两步：
  - `apt update`：刷新"仓库里有什么"的最新清单（只更新列表，不装东西）。
  - `apt upgrade`：按新清单，把已安装的软件升级到新版本（真正下载并安装）。

### 4. sudo 是什么

> **比喻**：有些操作只有"管理员"能做。你想做时，得先说一句"以管理员身份执行"——这句口令就是 **sudo**。

- **sudo**（superuser do）：以管理员（root）身份执行一条命令。
- 普通用户权限低，改系统、装软件都要加 `sudo`。
- 用法：`sudo 命令`，回车后输入你的登录密码（输入时屏幕不显示，属正常）。

## 命令演示

> 本节演示"第一次系统更新"。请先确保虚拟机能上网（有网或连了 Wi-Fi）。

### 演示 1：刷新软件源清单

```bash
sudo apt update
```

**逐行解释**：
- `sudo`：以管理员身份执行。
- `apt`：Ubuntu 的软件包管理工具（第 31、32 课会详细讲）。
- `update`：去软件源"仓库"拉取最新的软件清单。**这一步只更新清单，不会安装或删除任何软件**，安全。

### 演示 2：升级已安装的软件

```bash
sudo apt upgrade
```

**逐行解释**：
- `upgrade`：按照刚才更新的清单，把系统里已装的软件升级到新版本。
- 会先列出"要升级哪些、占用多少空间"，问你是否确认，输入 `y` 回车继续。
- ⚠️ 此步会真正下载并安装，**耗时较长，期间不要断电、不要关虚拟机**。建议升级前先打快照。

## 常见错误与排查

| 现象 | 可能原因 | 解决办法 |
| --- | --- | --- |
| `sudo apt update` 报"无法连接" | 没联网 | 先给虚拟机连上网（Wi-Fi 或有线）再试 |
| 输入 `sudo` 密码时屏幕没反应 | 正常现象 | Linux 输密码不显示任何字符，直接输完回车即可 |
| `apt update` 提示"没有权限" | 忘了加 `sudo` | 改成 `sudo apt update` |
| 升级到一半不敢关 | 正确！ | 千万别断电/关闭，等它跑完；升级前先打快照最稳妥 |
| 找不到快照按钮 | NanaBox 界面版本差异 | 通常在虚拟机"设置/操作"菜单里，找 Snapshot 字样 |

> 危险命令提醒：本课不涉及 `rm -rf`、`dd`、`fdisk`、`mkfs`、`iptables -F`。唯一要注意的是 `sudo apt upgrade` **会真正改动系统**，务必先打快照、升级中勿断电。

## 本课小结

- 桌面环境（Ubuntu 默认 GNOME）只是最外层的"壳"，可更换，底层不变。
- 快照 = 存档点，是实验的"后悔药"，操作前先打快照。
- 软件源 = 软件仓库；更新分两步：`update`（刷新清单）和 `upgrade`（真正升级）。
- `sudo` = 以管理员身份执行，装软件、改系统都要用。
