## 概念讲解

### 1. 内核是什么（Kernel）

> **比喻**：一辆汽车，方向盘、油门是"外壳"，但真正驱动它跑起来的是藏在里面的**发动机**。Linux 的**内核（Kernel）**就是这台发动机——它是系统最底层的核心，负责直接管理 CPU、内存、硬盘、网卡这些硬件。

- 你平时看不到内核，但它一刻不停地在工作。
- 内核最重要的三件事：管理**硬件**、分配**资源**、让**程序**能运行。

### 2. Shell 是什么

> **比喻**：你想让发动机加速，但不会直接用手去碰发动机，而是通过**方向盘**。Shell 就是你的"方向盘/翻译官"——你说人话，Shell 帮你翻译成内核听得懂的指令。

- **Shell**：一个让你和系统"对话"的程序。它解析命令，执行内置功能或启动其他程序；需要系统资源时，通过内核提供的接口请求服务。
- **bash** 是众多 Shell 里最常见的一种，本课程统一使用 bash。
- **终端（Terminal）**：本课指用于输入命令和显示结果的终端窗口，背景不一定是黑色。终端是"容器"，Shell 是"里面的人"。

### 3. 用户态与内核态（粗略概念）

> **比喻**：银行里，柜台外的"大堂"是普通客户能站的地方，柜台里的"金库"只有职员能进。Linux 把这种分界叫**用户态**和**内核态**。

- **用户态**：普通程序（比如你的浏览器、编辑器）运行的地方，权限低，不能随便碰硬件。
- **内核态**：内核运行的地方，权限最高，能直接操作硬件。
- 这种分层有助于**安全与稳定**，限制普通程序直接访问硬件；它不是系统绝不会出故障的保证。用户态/内核态也不等于普通用户/管理员，管理员启动的普通程序仍运行在用户态。

### 4. "一切皆文件"哲学

> **比喻**：Linux 把几乎所有的东西都当成"文件"来管理，就像把键盘、鼠标、硬盘都当成"写字的纸"——统一用同一套规则去读写。

- 你的文档是文件；目录（文件夹）是特殊的文件系统对象；许多设备通过 `/dev` 下的**设备文件入口**访问，并不是硬件本身变成了普通文档。
- 系统运行时的信息（比如内存情况）也是"文件"，放在 `/proc` 目录里。
- 好处：用类似读写文件的接口与多种系统对象交互。"一切皆文件"是设计思想的概括，不代表所有对象都是普通文件，也不代表都能随意读写。

### 5. 图形界面 vs 命令行

| 方式 | 特点 | 适合 |
| --- | --- | --- |
| 图形界面（GUI） | 用鼠标点点点，直观 | 日常操作、新手 |
| 命令行（CLI） | 敲命令，精确、可自动化 | 高效、批量、运维 |

- 两者都可以请求系统完成任务，只是交互方式不同。图形按钮背后可能直接调用程序功能，并不一定执行一条 Shell 命令。

## 命令演示

> 打开终端，逐条输入下面的命令，感受"Shell 传话"和"一切皆文件"。

### 演示 1：让 Shell 说句话

```bash
echo "你好，Linux"
```

**逐行解释**：
- `echo`：让 Shell 把你给的文字"回显"到屏幕上。
- bash 通常直接用内置的 `echo` 输出文字；输出过程会使用系统提供的服务，并不是把整条命令交给内核解析。

### 演示 2：我是谁？

```bash
whoami
```

**逐行解释**：
- `whoami`：问我"现在是以哪个用户身份在操作"，输出你的用户名。
- 说明系统时刻记得"你是谁"，这关系到后面的权限（第 08、09 课）。

### 演示 3：设备也是文件

```bash
ls /dev
```

**逐行解释**：
- `ls /dev`：列出 `/dev`（device，设备）目录。
- 常见名字有 `tty`（终端）、`null`、`zero`（虚拟设备）；硬盘可能叫 `sda`、`vda` 或 `nvme0n1`。设备名请以实际版本和虚拟机配置为准，不要求一定有 `sda`。

### 演示 4：系统信息也是文件

```bash
ls /proc
```

**逐行解释**：
- `ls /proc`：列出 `/proc` 目录，里面是系统运行时的"实时信息"，比如 CPU、内存状态。
- 这些信息并不是真的存在硬盘上，而是内核临时"摆"出来给你看的"文件"。

## 常见错误与排查

| 现象 | 可能原因 | 解决办法 |
| --- | --- | --- |
| 输入后出现续行提示 `>` | 英文引号没有成对闭合 | 按 `Ctrl + C` 取消本次输入，重新输入 `echo "你好"`；`echo 你好` 本身也能运行 |
| `whoami` 显示的不是我设的名字 | 你登录的是另一个用户 | 无妨，`whoami` 显示的是"当前用户" |
| `ls /dev` 输出一大堆，看不懂 | 正常，设备文件很多 | 先找 `tty`、`null`、`zero`；硬盘名称因配置而异 |
| 提示 `command not found` | 命令拼错或大小写不对 | Linux 命令区分大小写，`echo` 不能写成 `Echo` |
| 担心弄坏系统 | 本课命令都是"只看不改" | `echo`/`whoami`/`ls` 都不会修改任何东西，放心试 |

> 实验前建议使用已有快照。本课给出的命令仅查看或回显，无需管理员权限。设备文件可能涉及整块磁盘，勿向 `/dev` 或 `/proc` 写入内容；写入可能破坏数据或改变系统状态。

## 本课小结

- 内核是系统最底层的"发动机"，直接管理硬件；你平时看不到它。
- Shell 是"翻译官"，bash 是最常见的一种；终端是运行 Shell 的窗口。
- 系统分为用户态（普通程序）和内核态（内核），分层是为了安全。
- "一切皆文件"：文档、目录、设备、系统信息都可以当文件来看。
- 学会了 `echo`、`whoami`、`ls` 三个安全命令。
