## 概念讲解

### 1. 什么是文件系统

> **比喻**：一个图书馆要正常运转，得有一套管理规则——书放哪、怎么编号、怎么查。**文件系统（Filesystem）**就是硬盘上"怎么存放、怎么查找文件"的那套规则。

- 硬盘只是一块能存数据的"空地"，文件系统决定数据怎么摆、怎么找。
- Windows 常见的是 NTFS；Linux 最常见的是 **ext4**。
- 一块硬盘要先"格式化"成某种文件系统，才能正常存文件。

### 2. ext4 是什么

- **ext4**（Fourth Extended Filesystem）是 Linux 最广泛使用的文件系统。
- 特点：稳定可靠、支持大文件、支持大分区、性能好。
- Ubuntu 默认就用 ext4 格式化根分区。
- 它还有个"前辈"叫 ext3、ext2，ext4 是升级版。

### 3. inode 与数据块（重点）

> **比喻**：一本书 = 一个文件。书的**正文**存在"书架"上，而图书馆的**目录卡片**记录着这本书的编号、作者、大小、放在哪个书架。

- **数据块（Data Block）**：真正存放文件**内容**的地方，就像书架上的书页。
- **inode**（索引节点）：记录文件的**元信息**——大小、权限、属主、修改时间、以及"内容存在哪些数据块"，就像目录卡片。
- **注意**：inode 里**不存文件名**。

### 4. 文件名与 inode 的关系

> **比喻**：目录卡片上有编号，书名索引里写着"《小王子》→ 编号 123"。你要看书，先查书名索引得到编号，再按编号找卡片和正文。

- 文件名保存在**目录**里，目录里记录的是"文件名 → inode 号"的对应关系。
- 所以：**文件名只是"标签"，真正代表文件身份的是 inode 号**。
- 一个文件的内容可以有多个名字（第 10 课"硬链接"就是利用这一点）。

### 5. 挂载点是什么

> **比喻**：一块新硬盘（或分区）不能凭空出现，必须"挂"到目录树的某个树枝上，你才能通过那个目录访问它。

- **挂载点（Mount Point）**：一个目录，分区"挂"上去后，通过这个目录就能访问该分区的内容。
- 根分区挂在 `/`，其他分区/U 盘通常挂在 `/mnt`、`/media` 下的某个目录。
- 第 13 课会详细讲 `mount`、`umount`、`fstab`。

## 命令演示

### 演示 1：查看分区与挂载点

```bash
df -h
```

**逐行解释**：
- `df`：查看磁盘（分区）使用情况。
- `-h`：human，用人类易读的单位（KB/MB/GB）显示。
- 你会看到"文件系统"一列（如 `/dev/sda2`）和"挂载点"一列（如 `/`、`/boot`）。这就是"分区挂到目录"的直观体现。

### 演示 2：查看文件的 inode 信息

```bash
stat /etc/hostname
```

**逐行解释**：
- `stat`：显示某个文件的详细元信息（即 inode 里的内容）。
- 你会看到：大小（Size）、Inode 号、权限、属主、修改时间等。

### 演示 3：查看文件的 inode 号

```bash
ls -i /etc/hostname
```

**逐行解释**：
- `ls -i`：列出文件并显示它的 inode 号。
- 最前面那串数字就是 inode 号，同一个文件的 inode 号是唯一的。

## 随堂实验

> 完整步骤见 `labs/lesson-05.lab.md`。本课实验分三部分：

1. **实验 A**：运行 `df -h`，找出根分区的挂载点（文件系统类型可用 `df -hT` 查看）。
2. **实验 B**：运行 `stat`，查看一个文件的 inode 信息，读出它的 inode 号、大小、权限。
3. **实验 C**：运行 `ls -i`，对比不同文件的 inode 号，验证"每个文件 inode 号唯一"。

## 常见错误与排查

| 现象 | 可能原因 | 解决办法 |
| --- | --- | --- |
| `stat` 报"没有这个文件" | 路径写错 | 确认文件存在，如 `/etc/hostname` |
| `df -h` 输出看不懂 | 正常，列较多 | 只需看"文件系统""容量""挂载点"三列 |
| `ls -i` 的数字很长 | 正常 | 那串数字就是 inode 号，每文件唯一 |
| 分不清 inode 和文件名 | 概念混淆 | inode 是文件"身份证"，文件名是"标签" |
| 以为 inode 里存了文件名 | 常见误解 | inode 不存文件名，文件名存在目录里 |

> 危险命令提醒：本课不涉及 `rm -rf`、`dd`、`fdisk`、`mkfs`、`iptables -F`。`df`、`stat`、`ls -i` 都只是"查看"，绝对安全。

## 本课小结

- 文件系统是硬盘上"存文件、找文件"的规则；Linux 最常用 ext4。
- 文件内容存在**数据块**，元信息存在 **inode**（大小、权限、属主、时间等）。
- inode 里**不存文件名**；文件名存在目录里，是"指向 inode 的标签"。
- 分区要"挂"到某个目录（挂载点）才能使用，根分区挂在 `/`。
- 学会了 `df -h`、`stat`、`ls -i`。
