## 概念讲解

### 1. 什么是虚拟机（用生活比喻）

> **比喻**：你有一间大房子（你的真电脑）。你想在房子里再隔出一个小房间，里面放床、书桌，完全不影响大房间。这个小房间，就是用软件在真电脑里"划"出来的一台假电脑——**虚拟机（Virtual Machine，简称 VM）**。

- **真电脑**：我们叫它「宿主机（Host）」。
- **假电脑**：我们叫它「虚拟机（Guest）」，它有自己的 CPU 核心数、内存、硬盘，但实际上都是向宿主机"借"的资源。
- 虚拟机里装什么系统、怎么折腾，都不会弄坏你的真电脑。这正是我们学 Linux 最安全的方式。

### 2. NanaBox 是什么

**NanaBox** 是一款轻量的虚拟机软件，用来在 Windows 上创建和管理虚拟机。

- 它和 VirtualBox、Hyper-V 是同类工具。
- 本课程默认使用 NanaBox；如果你的环境不支持 NanaBox，请改用备用方案 **VirtualBox** 或 **Hyper-V**（步骤大同小异，只是按钮位置不同）。

### 3. ISO 镜像是什么

> **比喻**：以前装系统要用一张 DVD 光盘。现在这张光盘的内容被打包成一个文件，这个文件就叫做 **ISO 镜像**。

- 我们要去 Ubuntu 官网下载 `Ubuntu 26.04 LTS Desktop` 的 `.iso` 文件。这里的 **LTS** 是 Long Term Support（长期支持）的缩写，意思是官方会提供多年的更新维护，适合长期使用。
- 虚拟机启动时，会从这个 ISO 文件"读盘"，就像往光驱里插了一张安装光盘。

### 4. 给虚拟机分配 CPU、内存、磁盘

创建虚拟机时要"借"资源，三个关键配置：

| 资源 | 作用 | 建议值 |
| --- | --- | --- |
| CPU（处理器） | 运算速度 | 2 核 |
| 内存（RAM） | 临时运行空间 | 4 GB（4096 MB） |
| 磁盘（硬盘） | 长期存储 | 40 GB |

> **注意**：借出的资源是真电脑真实占用的，别贪多。例如给虚拟机分 8 GB 内存，你的真电脑就会少 8 GB。

### 5. swap 分区是什么

> **比喻**：内存就像你的**书桌**，正在用的文件都摊在桌上。书桌摆不下时，你把暂时不用的文件收到旁边的**柜子**里。这个"柜子"就是 **swap（交换分区）**。

- **swap**：在硬盘上划出一块区域，当内存不够用时，系统把暂时不用的数据临时搬到 swap，腾出内存给正在运行的程序。
- **为什么安装时要划分**：安装程序会让你给磁盘分区，其中就包含一块 swap 分区，它能在内存紧张时防止系统卡死或程序崩溃。
- swap 不是越大越好，通常 2–4 GB 对入门学习足够。

### 6. Linux 文件系统与 Windows 的差异

> **比喻**：Windows 的磁盘像**几个独立的抽屉**（C 盘、D 盘、E 盘），每个抽屉各自装东西；Linux 的磁盘像**一棵大树**，只有一个树根 `/`，所有东西都挂在树上。

- Windows：`C:\`、`D:\` 各自独立。
- Linux：一切从根目录 `/` 开始，没有 C 盘、D 盘。所有磁盘、U 盘、文件夹都"挂"在 `/` 这棵树的某个位置上。
- 常用目录（本课先认识三个）：
  - `/home`：每个用户的家目录（放你的个人文件）。
  - `/`：根目录，一切文件的起点。

### 7. 最常用指令预告（本课只预告，下几课细讲）

| 命令 | 作用 | 记忆方式 |
| --- | --- | --- |
| `ls` | 列出当前目录下的文件 | list（列出） |
| `cd` | 进入某个目录 | change directory（换目录） |
| `pwd` | 显示我现在在哪个目录 | print working directory（打印工作目录） |

## 命令演示

> 安装完系统后，打开「终端（Terminal）」，输入下面三条命令感受一下。

### 演示 1：我在哪里？列出文件

```bash
pwd
```

**逐行解释**：
- `pwd`：打印当前所在目录。第一次打开终端通常会显示 `/home/你的用户名`，意思是"我现在在家目录里"。

```bash
ls
```

**逐行解释**：
- `ls`：列出当前目录下有哪些文件和文件夹。刚装好的系统里可能是空的，或只有「桌面」「文档」等文件夹。

```bash
cd /
```

**逐行解释**：
- `cd /`：切换到根目录 `/`（那棵大树的树根）。

```bash
ls
```

**逐行解释**：
- 现在你会看到 `bin`、`etc`、`home`、`usr` 等一堆目录，这就是 Linux 文件系统的骨架。

> 回到自己家目录：输入 `cd ~`（`~` 代表你的家目录）。

## 常见错误与排查

| 现象 | 可能原因 | 解决办法 |
| --- | --- | --- |
| NanaBox 启动虚拟机报错"无法启动" | 没挂载 ISO、或 CPU 虚拟化未开启 | 检查虚拟机是否挂载了 Ubuntu 的 ISO；确认 BIOS 里开启了虚拟化（VT-x/AMD-V） |
| 装系统时找不到硬盘 | 创建虚拟机时没添加磁盘 | 回到虚拟机设置，添加一块虚拟磁盘 |
| 安装很卡 | 分给虚拟机的内存/CPU 太少 | 关机后调大内存到 4 GB、CPU 到 2 核 |
| 输入 `pwd` 提示"找不到命令" | 字母打错或空格问题 | 命令是全小写，注意 `pwd` 中间没有空格 |
| 装到一半想重来 | 安装过程有误 | 关掉虚拟机重新启动，从 ISO 再装一次即可（此时还没数据，可放心重来） |

> 危险命令提醒：本课不涉及 `rm -rf`、`dd`、`fdisk`、`mkfs`、`iptables -F` 等危险命令。安装过程中的"分区/抹掉磁盘"动作只发生在**虚拟机内部**，不会影响宿主机，但仍请按步骤操作、不要误选宿主机磁盘。

## 本课小结

- 虚拟机 = 用软件在真电脑里划出的"假电脑"，折腾坏了不影响真电脑。
- NanaBox 用于创建虚拟机；ISO 是"光盘文件"，用来装系统。
- 装 Ubuntu 时要分配 CPU、内存、磁盘，并划分 swap 分区（内存不够时的"备用柜子"）。
- Linux 文件系统是一棵树，只有一个根 `/`，没有 C 盘、D 盘。
- 认识了三个最常用的命令：`ls`（看）、`cd`（走）、`pwd`（我在哪）。
