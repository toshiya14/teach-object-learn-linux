## 概念讲解

### 1. 回顾：Linux 文件系统是一棵树

> **比喻**：一个真实的文件柜，最顶上的柜子是根目录 `/`，往下的每个抽屉、每个文件夹都从它长出来。

- 根目录写作一个斜杠：`/`。
- 一切文件、目录、设备都挂在 `/` 下面。
- 这套"什么目录放什么"的约定，有个标准叫 **FHS**（Filesystem Hierarchy Standard，文件系统层次结构标准）。

### 2. 常用目录逐个看

| 目录 | 装什么 | 生活比喻 |
| --- | --- | --- |
| `/` | 根目录，一切的起点 | 柜子的最顶层 |
| `/home` | 每个用户的"家"，放个人文件 | 每个人的私人房间 |
| `/etc` | 配置文件（各种设置） | 总开关面板 |
| `/var` | 会变化的数据（日志等） | 储物间，不断进进出出 |
| `/usr` | 系统和大部分软件 | 主仓库 |
| `/bin` | 最基本命令（如 `ls`、`cp`） | 常用工具箱 |
| `/tmp` | 临时文件，重启可能清空 | 临时垃圾桶 |

### 3. 绝对路径 vs 相对路径

> **比喻**：问路时，绝对路径是"从火车站出发……"（从根 `/` 讲起）；相对路径是"从我这儿往前走……"（从你当前所在位置讲起）。

- **绝对路径**：从根 `/` 开始写，例如 `/home/你的用户名/文档`。不管你现在在哪，它都指向同一个地方。
- **相对路径**：从你**当前所在目录**开始写，例如 `文档`（相对当前目录）。
- 判断方法：**开头是不是 `/`**。以 `/` 开头就是绝对路径，否则是相对路径。

### 4. 三个特殊符号

| 符号 | 含义 | 示例 |
| --- | --- | --- |
| `~` | 当前用户的家目录 | `cd ~` 回家 |
| `.` | 当前目录 | `ls .` 看当前目录 |
| `..` | 上一级目录 | `cd ..` 上一步 |

> **比喻**：`~` 是"我家"，`.` 是"我脚下"，`..` 是"上一层楼"。

## 命令演示

### 演示 1：我现在在哪

```bash
pwd
```

**逐行解释**：
- 打印当前目录。刚开终端一般在 `/home/你的用户名`。

### 演示 2：用绝对路径跳转

```bash
cd /etc
```

**逐行解释**：
- `/etc` 以 `/` 开头，是绝对路径。不管你在哪，都直接跳到根目录下的 `etc`。

```bash
pwd
```

**逐行解释**：
- 确认现在在 `/etc`。

### 演示 3：用相对路径跳转

```bash
cd ..
```

**逐行解释**：
- `..` 是相对路径，表示"上一级"。从 `/etc` 上去一级，回到 `/`。

```bash
pwd
```

**逐行解释**：
- 确认现在在 `/`。

### 演示 4：用 `~` 回家

```bash
cd ~
```

**逐行解释**：
- `~` 是"家目录"，等于 `/home/你的用户名`。一步到家。

### 演示 5：看一眼目录里有什么

```bash
ls /usr
```

**逐行解释**：
- 列出 `/usr` 目录的内容，你会看到 `bin`、`lib`、`share` 等子目录。

## 常见错误与排查

| 现象 | 可能原因 | 解决办法 |
| --- | --- | --- |
| `cd 文档` 报"没有那个文件或目录" | 你现在不在家目录，相对路径找不到 | 先 `cd ~` 回家，再 `cd 文档`；或用绝对路径 `/home/用户名/文档` |
| `pwd` 显示 `/` 而不是家目录 | 你之前 `cd /` 了 | 输入 `cd ~` 回家 |
| 分不清绝对/相对路径 | 记不清规则 | 记住：开头是 `/` 就是绝对路径 |
| `cd ..` 到 `/` 后再 `cd ..` 没反应 | `/` 已经是最高层，没有上一级 | 正常，`/` 就是树根，无法再往上 |
| 输入 `cd /usr` 成功但忘了自己在哪 | 正常 | 随时用 `pwd` 确认位置 |

> 危险命令提醒：本课不涉及 `rm -rf`、`dd`、`fdisk`、`mkfs`、`iptables -F`。`cd`、`pwd`、`ls` 都只是"走一走、看一看"，不会改动任何文件。

## 本课小结

- Linux 文件系统是一棵树，根是 `/`；目录放什么有 FHS 约定。
- 常用目录：`/home` 家目录、`/etc` 配置、`/var` 数据、`/usr` 软件、`/bin` 命令、`/tmp` 临时。
- 路径分两种：绝对路径（从 `/` 开始）、相对路径（从当前位置开始）。
- 三个符号：`~` 家目录、`.` 当前目录、`..` 上一级。
