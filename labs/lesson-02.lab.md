# 第 02 课 · 实验手册

> 目标：理解内核与 Shell，亲手运行第一个命令，体会"一切皆文件"。
> 预计时间：随堂 15 分钟（10 分钟演示跟练 + 5 分钟记录检查）+ 课后巩固。
> 注意：按本手册原样输入的命令仅查看或回显，无需管理员权限。勿向设备文件或 `/proc` 写入内容，以免破坏磁盘数据或改变系统状态。

## 实验前准备

1. 已安装并登录 Ubuntu 26.04 Desktop（第 01 课完成）。
2. 能打开终端（`Ctrl + Alt + T`）。
3. 建议先使用已有快照；若没有，按虚拟化软件实际支持的方式保存快照。

## 实验 A：让 Shell 说句话

### 步骤 1：打开终端

- 按 `Ctrl + Alt + T`。

> 你应当看到：终端窗口和等待输入的提示符，通常以 `$` 结尾；颜色和样式可能不同，请以实际版本为准。

### 步骤 2：回显一段文字

```bash
echo "你好，Linux"
```

> 你应当看到：屏幕输出 `你好，Linux`。
> 为什么：bash 通常用内置的 `echo` 回显文字，输出时使用系统服务；内核不会直接解析你输入的整条命令。

### 步骤 3：不带引号试试

```bash
echo 你好
```

> 你应当看到：也能输出 `你好`。
> 为什么：这段简单文字不加引号也能输出；英文双引号有助于保留空格，把整段文字作为一个整体传给命令。

## 实验 B：我是谁

```bash
whoami
```

> 你应当看到：输出当前有效用户的用户名；正常登录且未切换身份时，通常是安装时设置的用户名。
> 为什么：系统时刻记录"当前用户是谁"，这关系到后面的文件权限。

---

## 实验 C：设备也是文件

```bash
ls /dev
```

> 你应当看到：一长串名字，例如 `tty`、`null`、`zero` 等；硬盘可能叫 `sda`、`vda` 或 `nvme0n1`，请以实际版本和虚拟机配置为准。
> 为什么：`/dev`（device）提供访问设备的文件入口，其中既有硬件设备，也有虚拟设备，不是硬件本身变成了普通文件。

找出 3 个你认得的设备文件，填写到实验记录表。

---

## 实验 D：系统信息也是文件

```bash
ls /proc
```

> 你应当看到：一堆以数字命名的目录，以及 `cpuinfo`、`meminfo` 等文件。
> 为什么：`/proc` 里的"文件"是内核临时生成、反映系统运行状态的，并不真的存在硬盘上。
