# 第 03 课 · 实验手册

> 目标：认识桌面环境，学会打/恢复快照，完成第一次系统更新。
> 预计时间：随堂 15 分钟 + 课后巩固。
> 注意：`sudo apt upgrade` 会真正改动系统，升级前务必先打快照，升级中勿断电。

## 实验前准备

1. 已登录 Ubuntu 26.04 Desktop。
2. 虚拟机已能联网（Wi-Fi 或有线）。

---

## 实验 A：认识 GNOME 桌面

1. 点屏幕左下角「显示应用程序」（九宫格图标），浏览已安装的应用。
2. 打开「设置」（Settings），看看有哪些分类（网络、显示、用户等）。
3. 打开「文件」（Files），观察它和 Windows 资源管理器的异同。

> 你应当看到：应用列表、设置窗口、文件管理器都能正常打开。
> 为什么：这些图形程序都是桌面环境 GNOME 提供的，是系统最外层的一层"壳"。

---

## 实验 B：给虚拟机打第一个快照

> 此操作在 **NanaBox（宿主机）** 里进行，不是在 Ubuntu 系统里。

1. 在 NanaBox 里选中你的虚拟机（Ubuntu-26.04）。
2. 找到「快照 / Snapshot / 保存状态」相关按钮（因版本而异）。
3. 新建一个快照，命名为「刚装好系统」。

> 你应当看到：出现一个名为「刚装好系统」的快照记录。
> 为什么：快照 = 存档点，之后实验失败可一键"读档"回这个状态。

### 练习：装个软件再恢复

4. 回到 Ubuntu，用 `sudo apt install -y sl` 装一个叫 `sl` 的小火车程序（`-y` 表示自动确认，省去手动按 y；纯练习，第 32 课会细讲安装）。
5. 关机后，在 NanaBox 里把虚拟机**恢复**到「刚装好系统」快照。
6. 再次开机，输入 `sl` 回车。

> 你应当看到：提示找不到 `sl` 命令。
> 为什么：恢复快照后，系统回到了打快照的那一刻，之后装的 `sl` 消失了。这就是"读档"。

---

## 实验 C：第一次系统更新

### 步骤 1：刷新软件源清单

```bash
sudo apt update
```

> 你应当看到：输入密码后，滚动显示"正在读取软件包列表… 完成"，最后有"读取了 XXX 个软件包"。
> 为什么：`update` 只是拉取仓库最新清单，不安装、不删除任何软件。

### 步骤 2（可选）：升级软件

```bash
sudo apt upgrade
```

> 你应当看到：列出要升级的软件和占用空间，最后问 `Do you want to continue? [Y/n]`，输入 `y` 回车继续。
> 为什么：`upgrade` 按新清单真正下载并升级已装软件。
> ⚠️ 期间不要断电、不要关闭虚拟机。
