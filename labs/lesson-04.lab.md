# 第 04 课 · 实验手册

> 目标：熟悉目录结构，会用绝对/相对路径和特殊符号在系统里穿梭。
> 预计时间：随堂 15 分钟 + 课后巩固。
> 注意：本课命令 `cd`、`pwd`、`ls` 都只是"查看/移动"，不会修改任何文件。

## 实验前准备

1. 已登录 Ubuntu 26.04 Desktop。
2. 能打开终端。

---

## 实验 A：拜访常用目录

依次输入下面的命令，每到一个目录，先 `pwd` 确认，再 `ls` 看一眼。

```bash
cd /
pwd
ls
```

> 你应当看到：`pwd` 显示 `/`；`ls` 列出 `bin`、`etc`、`home`、`usr`、`var` 等。
> 为什么：`/` 是根目录，一切从这里开始。

```bash
cd /etc
pwd
ls
```

> 你应当看到：`pwd` 显示 `/etc`；`ls` 列出大量 `.conf` 配置文件。
> 为什么：`/etc` 专门存放配置文件。

```bash
cd /usr
pwd
ls
```

> 你应当看到：`pwd` 显示 `/usr`；`ls` 列出 `bin`、`lib`、`share` 等。
> 为什么：`/usr` 存放系统和软件。

```bash
cd /var
pwd
ls
```

> 你应当看到：`pwd` 显示 `/var`；`ls` 列出 `log`、`cache` 等。
> 为什么：`/var` 存放会变化的数据，如日志。

```bash
cd /tmp
pwd
ls
```

> 你应当看到：`pwd` 显示 `/tmp`。
> 为什么：`/tmp` 是临时目录。

## 实验 B：用相对路径向上

```bash
cd ..
pwd
```

> 你应当看到：从 `/tmp` 回到了 `/`。
> 为什么：`..` 表示上一级目录。

再连按几次（在 `/` 时再 `cd ..` 不会动）：

```bash
cd ..
pwd
```

> 你应当看到：仍在 `/`。
> 为什么：`/` 是树根，没有上一级了。

## 实验 C：用特殊符号快速跳转

```bash
cd ~
pwd
ls .
cd ..
pwd
```

> 你应当看到：`cd ~` 后 `pwd` 显示 `/home/你的用户名`；`ls .` 列出家目录内容；`cd ..` 后回到 `/home`。
> 为什么：`~` 是家目录，`.` 是当前目录，`..` 是上一级。
