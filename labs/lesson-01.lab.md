# 第 01 课 · 实验手册

> 目标：亲手用 NanaBox 创建虚拟机，安装 Ubuntu 26.04 Desktop，并完成第一次终端操作。
> 预计时间：随堂 20 分钟 + 课后巩固。
> 注意：本课实验全程在**虚拟机内部**操作，不会影响你的宿主机。装坏了随时重来。

## 实验前准备

1. 一台 Windows 电脑（宿主机），已安装 **NanaBox**。
   - 若无法使用 NanaBox，请改用 **VirtualBox** 或 **Hyper-V**，步骤类似。
2. 下载 **Ubuntu 26.04 LTS Desktop** 的 ISO 镜像文件。
   - 官方地址：https://ubuntu.com/download/desktop
   - 文件名类似：`ubuntu-26.04-desktop-amd64.iso`（以实际下载为准）。

> 下载前请确认你的电脑支持 64 位系统；如不确定，先以官方页面默认选项为准。

---

## 实验 A：创建虚拟机

### 步骤 1：打开新建向导

1. 打开 NanaBox。
2. 点击「新建虚拟机」（或 New / 新建 按钮）。

> 你应当看到：一个创建向导或配置窗口。

### 步骤 2：填写名称与资源

按下表填写：

| 配置项 | 填什么 | 为什么 |
| --- | --- | --- |
| 名称 | `Ubuntu-26.04` | 方便以后认出这台虚拟机 |
| CPU | 2 核 | 保证系统流畅 |
| 内存 | 4096 MB（4 GB） | 运行桌面系统的最低舒适配置 |
| 磁盘 | 新建 40 GB 动态磁盘 | 40 GB 够学习和实验用 |

> 你应当看到：磁盘大小为 40 GB、内存 4096 MB 的配置信息。

### 步骤 3：挂载 ISO

1. 找到「光驱 / CD / DVD」或「启动 ISO」相关选项。
2. 选择刚才下载的 Ubuntu ISO 文件，挂载上去。

> 你应当看到：虚拟机设置里显示已挂载该 ISO 文件。

### 步骤 4：启动虚拟机

1. 点击「启动 / Start」。
2. 虚拟机会从 ISO 引导，进入 Ubuntu 安装界面。

> 你应当看到：出现 Ubuntu 的启动画面或安装欢迎界面。这说明实验 A 成功。

---

## 实验 B：安装 Ubuntu 26.04 Desktop

> 界面文案可能因版本略有不同，请以实际版本为准。以下按典型流程描述。

### 步骤 1：选择语言

- 选择「中文（简体）」（或 English，按你的习惯）。

### 步骤 2：键盘与网络

- 保持默认键盘布局。
- 若有网络，可连接 Wi-Fi 或有线网络（可选，装完后也能连）。

### 步骤 3：选择安装方式

- 选择「**交互式安装**」（Interactive installation），跟着向导一步步走。

### 步骤 4：磁盘分区（重点）

> ⚠️ 危险提示：此步会**擦除所选磁盘上的数据**。请务必确认选中的是"虚拟机内部的 40 GB 磁盘"，而不是你的宿主机硬盘。虽然本课在虚拟机内操作，仍不要选错对象。

1. 在分区界面，新手请选择「**使用整块磁盘**」（让安装程序自动分区）。
   - 进阶可选「手动分区」，但本课建议自动。
2. 确认自动分区后，观察它生成的方案，通常包含：
   - **根分区 `/`**：放系统主体（约占绝大部分空间）。
   - **swap 分区**：交换分区（通常 2–4 GB）。
3. **记录你的分区方案**（这是作业）：

   ```
   磁盘大小：____ GB
   根分区 / ：____ GB
   swap 分区：____ GB
   ```

> 你应当看到：分区界面显示了 `/` 和 `swap` 两块分区。

### 步骤 5：创建用户

- 设置你的用户名、计算机名、登录密码。
- **请记住用户名和密码**，后续每节课都要用。

### 步骤 6：等待安装并重启

- 等待进度条走完。
- 安装完成后按提示重启，进入刚装好的 Ubuntu 桌面。

> 你应当看到：Ubuntu 桌面出现，说明实验 B 成功。

## 实验 C：第一次终端操作

### 步骤 1：打开终端

- 方法一：按快捷键 `Ctrl + Alt + T`。
- 方法二：点击左下角「显示应用程序」→ 搜索「终端（Terminal）」。

> 你应当看到：一个黑色（或深色）窗口，里面有一行提示符，末尾通常是 `$`。

### 步骤 2：我在哪里？

输入并回车：

```bash
pwd
```

> 你应当看到：输出类似 `/home/你的用户名`。
> 为什么：`pwd` 打印当前目录；第一次打开终端默认落在你的家目录 `/home/用户名`。

### 步骤 3：这里有什么？

```bash
ls
```

> 你应当看到：列出家目录下的文件夹，例如「桌面」「文档」「下载」等（也可能为空）。
> 为什么：`ls` 列出当前目录的内容；家目录下默认就有这些文件夹。

### 步骤 4：去根目录看看

```bash
cd /
```

```bash
ls
```

> 你应当看到：列出一堆目录名，如 `bin`、`etc`、`home`、`usr`、`var`。这就是 Linux 文件系统的骨架。
> 为什么：`cd /` 把当前目录切换到根目录 `/`，再 `ls` 列出的就是系统最顶层的目录结构。

### 步骤 5：回家目录

```bash
cd ~
```

> 你应当看到：提示符又变回 `/home/你的用户名` 附近。
> 为什么：`~` 是家目录的简写，`cd ~` 就是回到自己的家目录。
