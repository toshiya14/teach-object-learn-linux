# 第 05 课 · 实验手册

> 目标：理解文件系统、inode 与数据块，会用 df/stat/ls -i 查看相关信息。
> 预计时间：随堂 15 分钟 + 课后巩固。
> 注意：本课命令 `df`、`stat`、`ls -i` 都只读，不修改任何文件。

## 实验前准备

1. 已登录 Ubuntu 26.04 Desktop。
2. 能打开终端。

---

## 实验 A：查看分区与挂载点

```bash
df -h
```

> 你应当看到：一张表，包含"文件系统""容量""已用""可用""挂载点"等列。
> 为什么：`df` 显示各分区的使用情况，`-h` 让单位变成 GB/MB 好读。

**找到并记录**：

- 根分区的"文件系统"名称（形如 `/dev/sda2` 或 `/dev/mapper/...`）
- 根分区的"挂载点"（应为 `/`）
- 文件系统类型（`df -h` 若没显示类型，可改用 `df -hT` 查看）

---

## 实验 B：查看文件的 inode 信息

```bash
stat /etc/hostname
```

> 你应当看到：类似下面的输出（数字因人而异）。

```
  文件：/etc/hostname
  大小：7               块：8          IO 块：4096   普通文件
设备：...  Inode：1234567    硬链接：1
权限：(0644/-rw-r--r--)  Uid：(0/root)   Gid：(0/root)
最近访问：...
最近更改：...
最近改动：...
```

> 为什么：`stat` 把文件的 inode 元信息完整显示出来。

**记录三项**：Inode 号、大小、权限。

---

## 实验 C：对比不同文件的 inode 号

```bash
ls -i /etc/hostname /etc/hosts
```

> 你应当看到：两行，每行最前面是一串数字（inode 号），后面是文件名。
> 为什么：`ls -i` 显示每个文件的 inode 号。

再随便找一个文件对比：

```bash
ls -i /etc/passwd
```

> 你应当看到：另一个不同的 inode 号。
> 为什么：同一分区内，每个文件的 inode 号唯一。
