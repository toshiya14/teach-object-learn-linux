# 什么是虚拟机

[动画1] 真电脑 = 宿主机（Host）

[动画2] 虚拟机 = 用软件划出的"假电脑"（Guest）

[动画3] 比喻：大房子里用屏风隔出一个小房间

```
真电脑（宿主机）
 └─ 虚拟机（NanaBox 里运行）
     ├─ CPU 2 核
     ├─ 内存 4 GB
     └─ 磁盘 40 GB
```

<!-- 解说：虚拟机就是用软件在真电脑里划出来的一台假电脑。就像在大房子里用屏风隔出一个小房间，小房间里怎么折腾都不会弄坏大房子。所以我们学 Linux 最安全的方式，就是先在虚拟机里练手。 -->
---

# NanaBox 是什么

[动画1] 一款轻量的虚拟机软件

[动画2] 和 VirtualBox / Hyper-V 是同类工具

[动画3] 本课程默认使用 NanaBox

[动画4] 不支持时，改用 VirtualBox / Hyper-V

<!-- 解说：NanaBox 是一款轻量的虚拟机软件，用来在 Windows 上创建和管理虚拟机。它和 VirtualBox、Hyper-V 是同一类工具。本课程默认用 NanaBox，如果你的电脑不支持，就用 VirtualBox 或者 Hyper-V 代替，步骤差不多。 -->
---

# 什么是 ISO 镜像

[动画1] 比喻：光盘的内容被打包成一个文件

[动画2] 去 Ubuntu 官网下载 Ubuntu 26.04 LTS Desktop 的 .iso

[动画3] 虚拟机从 ISO"读盘"，就像插入安装光盘

```
下载 → ubuntu-26.04-desktop.iso
         │
         ▼
     挂载到虚拟机光驱
```

<!-- 解说：以前装系统要一张 DVD 光盘，现在这张光盘的内容被打包成一个文件，叫 ISO 镜像。我们要去 Ubuntu 官网下载 Ubuntu 26.04 桌面版的 iso 文件。虚拟机启动时就从它读盘，就像往光驱里插了张安装盘。 -->
---

# 给虚拟机分配资源

[动画1] CPU —— 运算速度，建议 2 核

[动画2] 内存 —— 临时运行空间，建议 4 GB

[动画3] 磁盘 —— 长期存储，建议 40 GB

[动画4] 借的资源会真实占用，别贪多

<!-- 解说：创建虚拟机时要借三个资源。CPU 管运算速度，建议两核；内存是临时运行空间，建议四个 G；磁盘是长期存储，建议四十个 G。记住，借出去的资源是真实占用的，分太多你的真电脑会变慢。 -->
---

# swap 分区是什么

[动画1] 内存 = 书桌，swap = 柜子

[动画2] 书桌摆不下时，把不用的文件收进柜子

[动画3] 内存不够时，数据临时搬到 swap

[动画4] 防止系统卡死或程序崩溃

```
内存（书桌）──满──▶ swap（柜子）
     临时腾地方
```

<!-- 解说：swap 交换分区，说白了就是内存不够时的备用空间。打个比方，内存就像书桌，正在用的文件摊在桌上；桌子摆不下了，就把暂时不用的文件收进柜子。这个柜子就是 swap。装上它，内存紧张时系统不容易卡死。 -->
---

[动画1] 打开 NanaBox，点「新建虚拟机」

[动画2] 名称：Ubuntu-26.04

[动画3] 分配：CPU 2 核、内存 4096 MB

[动画4] 新建一块 40 GB 虚拟磁盘

```
新建虚拟机
├─ 名称   Ubuntu-26.04
├─ CPU    2 核
├─ 内存   4096 MB
└─ 磁盘   40 GB
```

<!-- 解说：现在动手。打开 NanaBox，点新建虚拟机。名称填 Ubuntu-26.04。CPU 给两核，内存给 4096 兆，也就是四个 G。然后新建一块四十 G 的虚拟磁盘。这些数字都按建议值来就行。 -->

# 安装 Ubuntu 26.04（下）：分区与 swap

[动画1] 选择「整块磁盘」或「手动分区」

[动画2] 新手建议：让安装程序自动分区

[动画3] 自动分区通常包含：根分区 + swap

[动画4] 记录你的分区方案

```
磁盘 40 GB
├─ / (根分区)    约 37 GB
└─ swap (交换分区) 约 3 GB
```

<!-- 解说：分区这里，新手建议直接选自动分区，让安装程序帮你安排。它通常会划出两个东西，一个是根分区，放系统；另一个就是刚才讲的 swap 交换分区。装完后记得把你的分区方案记下来，这是今天的作业。 -->

# Linux 文件系统 vs Windows

[动画1] Windows：几个独立抽屉（C 盘、D 盘）

[动画2] Linux：一棵树，只有一个根 /

[动画3] 所有东西都挂在 / 这棵树上

```
Windows            Linux
C:\  D:\  E:\      /
                   ├─ home
                   ├─ etc
                   ├─ usr
                   └─ var
```

<!-- 解说：装完系统，来理解 Linux 的文件系统。Windows 的磁盘像几个独立的抽屉，C 盘、D 盘各装各的。Linux 不一样，它像一棵树，只有一个根，就是斜杠。所有磁盘、文件夹都挂在树上。记住一句话：没有 C 盘 D 盘，一切从根开始。 -->
---

# 三个超常用命令

[动画1] `pwd` —— 我在哪个目录？

[动画2] `ls` —— 这里有什么？

[动画3] `cd` —— 去某个目录

```bash
pwd      # 打印当前目录
ls       # 列出文件
cd /     # 进入根目录
```

<!-- 解说：最后认识三个命令，以后天天都要用。pwd 告诉你现在在哪；ls 列出当前目录有什么；cd 用来切换目录。现在先眼熟，后面几课会详细讲。 -->
