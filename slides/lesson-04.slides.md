# Linux 文件系统是一棵树

[动画1] 根目录是 `/`

[动画2] 一切从根长出来

[动画3] FHS 约定"什么目录放什么"

```
/
├─ home   用户家目录
├─ etc    配置文件
├─ var    变化的数据
├─ usr    系统软件
├─ bin    基本命令
└─ tmp    临时文件
```

<!-- 解说：Linux 的文件系统是一棵树，最顶上是根目录，写作一个斜杠。所有的文件、目录都从它长出来。这套"什么目录放什么"的约定有个标准叫 FHS。记住一句话：一切从根开始。 -->
---

# 常用目录逐个看

[动画1] /home —— 每个人的"私人房间"

[动画2] /etc —— 总开关面板（配置）

[动画3] /var —— 储物间（日志等）

[动画4] /usr —— 主仓库（软件）

[动画5] /bin —— 工具箱（基本命令）

[动画6] /tmp —— 临时垃圾桶

<!-- 解说：这几个目录最好都记住。home 是每个用户的家，放个人文件；etc 放配置文件，像总开关面板；var 放会变化的数据，比如日志；usr 放系统软件；bin 放最基本命令；tmp 放临时文件。 -->
---

# 绝对路径 vs 相对路径

[动画1] 绝对路径：从根 `/` 开始写

[动画2] 相对路径：从当前位置开始写

[动画3] 判断方法：开头是不是 `/`

[动画4] 比喻：从火车站出发 vs 从我这儿出发

```
绝对路径  /home/你的用户名/文档
相对路径  文档
          （相对当前目录）
```

<!-- 解说：路径分两种。绝对路径从根斜杠开始写，比如 home 你的用户名 文档，不管你在哪都指向同一个地方。相对路径从你当前位置开始写，比如直接写"文档"。怎么判断？看开头是不是斜杠，是就是绝对路径。 -->
---

# 三个特殊符号

[动画1] `~` = 我的家目录

[动画2] `.` = 当前目录

[动画3] `..` = 上一级目录

[动画4] 比喻：我家 / 我脚下 / 上一层楼

```bash
cd ~      # 回家
ls .      # 看当前目录
cd ..     # 上一层
```

<!-- 解说：三个特殊符号要牢记。波浪号代表我的家目录，点代表当前目录，两个点代表上一级。就像我家、我脚下、上一层楼。配合 cd 和 ls 用起来非常方便。 -->
---

# 命令演示 1：我在哪 + 绝对路径

[动画1] pwd 看当前位置

[动画2] cd /etc 用绝对路径跳转

[动画3] 再 pwd 确认

```bash
pwd
cd /etc
pwd
```

[动画4] 输出：先显示家目录，再显示 `/etc`

<!-- 解说：先输入 pwd 看自己在哪，一般在 home 你的用户名。然后 cd 斜杠 etc，这是绝对路径，直接跳到根目录下的 etc。再 pwd 确认，现在显示 etc。绝对路径的好处是，不管你在哪都能直达。 -->
---

# 命令演示 2：相对路径

[动画1] cd .. 表示上一级

[动画2] 从 /etc 上去一级到 /

[动画3] pwd 确认

```bash
cd ..
pwd
```

[动画4] 输出：`/`

<!-- 解说：现在在 etc，输入 cd 两个点，表示上一级，就回到了根目录斜杠。pwd 确认一下，显示一个斜杠。这就是相对路径，它跟你当前的位置有关。 -->
---

# 命令演示 3：回家与查看

[动画1] cd ~ 一步到家

[动画2] ls /usr 看 usr 里有什么

```bash
cd ~
ls /usr
```

[动画3] 会看到 bin、lib、share 等子目录

<!-- 解说：输入 cd 波浪号，一步回到你的家目录。再输入 ls 斜杠 usr，看看 usr 这个软件仓库里有什么，你会看到 bin、lib、share 等一堆子目录。 -->
