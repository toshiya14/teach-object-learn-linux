# 什么是文件系统

[动画1] 比喻：图书馆的管理规则

[动画2] 硬盘只是"空地"，文件系统是"怎么摆怎么找"的规则

[动画3] Windows 用 NTFS，Linux 用 ext4

[动画4] 硬盘要先格式化才能存文件

```
硬盘（空地） ──格式化──▶ 文件系统（有规则的仓库）
                         ├─ 怎么存
                         └─ 怎么找
```

<!-- 解说：文件系统就像图书馆的管理规则。硬盘本身只是一块能存数据的空地，文件系统决定数据怎么摆、怎么找。Windows 常用 NTFS，Linux 最常用 ext4。硬盘要先格式化成某种文件系统，才能正常存文件。 -->
---

# ext4 是什么

[动画1] Linux 最广泛使用的文件系统

[动画2] Fourth Extended = 第四代扩展文件系统

[动画3] 稳定、支持大文件大分区、性能好

[动画4] Ubuntu 默认用它格式化根分区

```
ext2 → ext3 → ext4（升级版）
```

<!-- 解说：ext4 是 Linux 里用得最广的文件系统，全称第四代扩展文件系统。它稳定可靠，支持大文件和大分区，性能也好。Ubuntu 装系统时，默认就用 ext4 来格式化根分区。它还有 ext2、ext3 这些前辈。 -->
---

# inode 与数据块（重点）

[动画1] 数据块 = 书架，真正放文件内容

[动画2] inode = 目录卡片，记录元信息

[动画3] inode 记录：大小、权限、属主、时间、内容在哪

[动画4] inode 里不存文件名

```
文件 = 数据块（正文） + inode（目录卡片）
                    ├─ 大小
                    ├─ 权限
                    ├─ 属主
                    └─ 时间
```

<!-- 解说：这是今天的重点。一个文件分成两部分：数据块真正放内容，就像书架上的书页；inode 记录元信息，就像图书馆的目录卡片，写着大小、权限、属主、时间，以及内容放在哪些数据块。特别记住，inode 里不存文件名。 -->
---

# 文件名与 inode 的关系

[动画1] 文件名存在"目录"里

[动画2] 目录里记录：文件名 → inode 号

[动画3] 文件名只是"标签"

[动画4] 真正代表文件身份的是 inode 号

```
目录（书名索引）       inode（卡片）
《小王子》 ──▶ 123 ──▶ 大小/位置
《Le Petit Prince》─▶ 123（同一个文件！）
```

<!-- 解说：文件名和 inode 是分开的。文件名存在目录里，目录里记的是"这个名字对应哪个 inode 号"。所以文件名只是个标签，真正代表文件身份的是 inode 号。这也意味着，一个文件可以有好几个名字，后面讲硬链接时会用到。 -->
---

# 挂载点是什么

[动画1] 分区不能凭空出现，要"挂"到目录上

[动画2] 挂载点 = 用来挂分区的那个目录

[动画3] 根分区挂在 /

[动画4] U 盘常挂在 /media 下

```
分区A ──挂载──▶ /        （根分区）
分区B ──挂载──▶ /boot
U盘   ──挂载──▶ /media/xxx
```

<!-- 解说：挂载点这个概念先混个眼熟。一块分区不能凭空出现在系统里，必须挂到目录树上的某个目录，那个目录就是挂载点。根分区挂在斜杠，U 盘通常挂在 media 目录下。第 13 课会详细讲 mount 和 umount。 -->
---

# 命令演示 1：df -h

[动画1] 查看分区和挂载点

[动画2] -h 用人类易读的单位

```bash
df -h
```

[动画3] 看到"文件系统"和"挂载点"两列

<!-- 解说：第一个命令，df 空格 减 h。它查看磁盘分区的使用情况，h 表示用 GB、MB 这些好读的单位。输出里重点看两列：文件系统列，比如 dev sda2；挂载点列，比如斜杠、boot。这就是分区挂到目录的直接体现。 -->
---

# 命令演示 2：stat

[动画1] 查看文件的 inode 元信息

```bash
stat /etc/hostname
```

[动画2] 会显示：Inode 号、大小、权限、属主、时间

<!-- 解说：第二个命令，stat 后面跟一个文件路径。它把这个文件的 inode 元信息原原本本显示出来，包括 Inode 号、大小、权限、属主、最后修改时间。这些就是目录卡片上的内容。 -->
---

# 命令演示 3：ls -i

[动画1] 列出文件并显示 inode 号

```bash
ls -i /etc/hostname
```

[动画2] 最前面那串数字就是 inode 号

[动画3] 每个文件的 inode 号唯一

<!-- 解说：第三个命令，ls 减 i。它列出文件，并在前面显示 inode 号。最前面那串数字就是 inode 号，同一个分区里每个文件的 inode 号都是唯一的，就像身份证号。 -->
