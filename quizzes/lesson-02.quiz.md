# 第 02 课 · 小测验

> 共 5 题，每题 20 分。答案见文件末尾。

**1. Linux 里，"内核（Kernel）"的作用最接近以下哪个比喻？**

A. 汽车的发动机，藏在底层驱动一切
B. 汽车的方向盘，供人操作
C. 汽车的车身外壳
D. 汽车的轮胎

**2. 关于 Shell，下列说法正确的是？**

A. Shell 是电脑的硬件
B. Shell 是你和系统之间的"翻译官"，bash 是其中一种
C. Shell 只能显示图片
D. Shell 就是内核

**3. 终端（Terminal）和 Shell 的关系是？**

A. 完全无关
B. 终端是运行 Shell 的"窗口/容器"
C. Shell 是运行终端的窗口
D. 二者是同一个东西

**4. "一切皆文件"的意思是？**

A. Linux 里只有文档一种文件
B. 文档、目录、许多设备和系统信息有文件形式的访问入口
C. 只能读写 U 盘
D. 文件必须放在桌面

**5. 想在终端输出"我是谁"（当前用户名），应该输入？**

A. `pwd`
B. `ls`
C. `whoami`
D. `echo`

---

## 答案

| 题号 | 答案 | 解析 |
| --- | --- | --- |
| 1 | A | 内核是系统最底层的核心，直接管理硬件，类似发动机 |
| 2 | B | Shell 是用户与内核之间的翻译官，bash 是最常见的一种 |
| 3 | B | 本课使用的终端窗口负责输入输出，其中运行着 Shell 程序 |
| 4 | B | 许多设备通过 /dev 的设备文件访问，/proc 提供运行信息；不代表所有对象都是普通文件 |
| 5 | C | `whoami` 显示当前用户名；`pwd` 是目录，`ls` 是列文件 |
