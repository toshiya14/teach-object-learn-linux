# 第 03 课 · 小测验

> 共 5 题，每题 20 分。答案见文件末尾。

**1. Ubuntu 默认的桌面环境叫什么？**

A. Windows
B. GNOME
C. KDE
D. bash

**2. 虚拟机"快照（Snapshot）"最像什么？**

A. 一个新装的软件
B. 游戏存档点，可以随时"读档"回去
C. 一块新硬盘
D. 一个网络加速器

**3. `sudo apt update` 的作用是？**

A. 立即升级所有软件
B. 删除系统
C. 刷新软件源的软件清单（不安装任何东西）
D. 安装 Ubuntu 系统

**4. `sudo` 的作用是？**

A. 关机
B. 以管理员身份执行命令
C. 列出文件
D. 连接网络

**5. 关于 `apt update` 和 `apt upgrade`，正确的是？**

A. 两者完全一样
B. update 刷新清单，upgrade 才真正升级软件
C. upgrade 只刷新清单
D. update 会删除软件

---

## 答案

| 题号 | 答案 | 解析 |
| --- | --- | --- |
| 1 | B | Ubuntu 默认桌面环境是 GNOME |
| 2 | B | 快照记录某时刻状态，可恢复，类似游戏存档 |
| 3 | C | update 只刷新软件源清单，不安装 |
| 4 | B | sudo = superuser do，以管理员身份执行 |
| 5 | B | update 刷新清单，upgrade 才下载并升级 |
