# 第 01 课 · 小测验

> 共 5 题，每题 20 分。答案见文件末尾。

**1. 关于虚拟机，下列说法正确的是？**

A. 虚拟机是一台独立的物理电脑
B. 虚拟机是用软件在真电脑里"划"出来的假电脑，占用真电脑的资源
C. 虚拟机里装系统一定会弄坏真电脑
D. 虚拟机不能安装 Linux

**2. 安装 Ubuntu 时，"swap 分区"的主要作用是？**

A. 存放所有用户文件
B. 内存不够时，作为临时备用空间，防止系统卡死
C. 加快上网速度
D. 存放系统日志

**3. Linux 文件系统和 Windows 最大的区别是？**

A. Linux 有 C 盘和 D 盘
B. Linux 一切从根目录 `/` 开始，是一棵树，没有 C 盘 D 盘
C. Linux 不能存文件
D. Linux 文件名不能有字母

**4. 想在终端查看"我现在在哪个目录"，应该输入？**

A. `ls`
B. `cd`
C. `pwd`
D. `dir`

**5. 想在终端列出当前目录下有哪些文件，应该输入？**

A. `pwd`
B. `ls`
C. `cd`
D. `run`

---

## 答案

| 题号 | 答案 | 解析 |
| --- | --- | --- |
| 1 | B | 虚拟机是宿主机上运行的软件模拟出的电脑，资源来自宿主机 |
| 2 | B | swap 是交换分区，内存紧张时临时腾地方，防止系统卡死或崩溃 |
| 3 | B | Linux 是单一树形结构，根为 `/`，无盘符概念 |
| 4 | C | `pwd` = print working directory，打印当前目录 |
| 5 | B | `ls` = list，列出目录内容 |
